# What an agent can do

A connected agent reads, searches and writes through Ponistra's tools, always with the rights of the person who connected it.

## How to use it

1. Connect the agent under {t:settings.title}, {t:agents.title}.
2. Ask the agent in its own window to find, read or prepare something in Ponistra.
3. Review what the agent writes into a document and accept or reject it as proposals.
4. Open a reply the agent drafted over the message, or a new message among those you have not sent, then send or drop it.

## How it works

An agent can read:

- who it is and on whose behalf it works;
- search results among documents, files, mail, events, tasks and people, as in the search box;
- a folder's content, your documents, what is shared with you and the company's folders;
- a document's tabs, a file's text page by page and a board's page;
- the latest messages of a folder, yours or a shared mailbox's you read, the unread alone if it asks;
- a message with its attachments and an attachment's text, but never the file itself;
- your calendars, events, tasks and contacts;
- your mail [collections](help:mail/collections);
- the articles of this help, in your language;
- how an action it started went.

An agent can write:

- a new empty document, into a chosen folder or at the top of your documents;
- text into a tab, as proposals you accept or reject, in the action {t:action.agentEdit} that is undone at once;
- the actions of the document's menu, except accepting and rejecting proposals and actions over several documents;
- a draft reply, forward or new message, which you send;
- actions on messages, at once and in Ponistra only: read and unread, the flag, moving to a folder, snoozing, waiting for an answer, blocking senders and a rule for where their mail goes, adding to your collection from your own mailbox only, in a shared mailbox only where you may change it;
- an event in a calendar, without attendees, and a task;
- a link on your page of links, in the group it names;
- a board, a page of HTML you open in Ponistra, with the data the board keeps.

## Limits

- An agent deletes nothing, except data a board keeps.
- An agent does not send mail and does not add attendees to an event.
- An agent does not delete messages for good and does not sort them with the installation's model; it can move them to {t:mail.role.trash}.
- When an agent rewrites a board, its previous page stays as a version.
- A link whose address is already in the group stays as you left it.
