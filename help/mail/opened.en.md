# Read within the organisation

A sender sees which colleagues in the same installation opened their message, and when.

## How to use it

1. Send a message to colleagues in the same installation.
2. In the sent folder the message shows how many colleagues opened it. When all have, the mark is {t:mail.openedAll}.
3. Open the message. Below its heading, as {t:mail.openedBy}, stands how many opened it out of the total, then a list of colleagues with a date or the mark {t:mail.notOpened}.
4. {t:mail.outside} shows how many recipients are outside the installation; opening is not followed for them.

## How it works

Only actually opening a message counts. Marking it read does not. Only the sender sees this. Nothing is asked of the recipient or leaves the installation, and no read receipt is sent.

An administrator turns it on for all users of the installation, as {t:mail.openedSetting}. Turning it off deletes everything noted so far.

## Limits

Opening is followed only among users of the same installation who hold the message.
