# Draft replies

A draft reply is a reply prepared by an outside agent, waiting for you to review and send it.

## How to use it

1. Open {t:mail.role.drafts}. At the top of the folder is {t:mail.waitingDrafts}.
2. Press a draft. The message it answers opens, with a {t:mail.draft} box and the agent's name.
3. With the button in the box open the draft, edit it in the [form for writing](help:mail/composing) and send it.
4. If you do not want it, press {t:mail.dropDraft}.

## How it works

An agent you let into your account can prepare a reply but cannot send it. The message goes nowhere until you send it. On opening, the draft's text enters the form, and from there everything goes as with any reply.

## Limits

An agent can prepare only a reply to an existing message, not a new message. A draft is not the same as an unfinished message you began yourself; those are under {t:mail.unsentTitle}.
