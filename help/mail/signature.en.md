# Signature

A signature goes by itself below each new message and reply, shared by all accounts or for each one apart.

## How to use it

1. Long-press the account's name in Mail's left column or right-click it.
2. Choose {t:mail.signature}.
3. Under {t:mail.signature.scope} choose {t:mail.signature.shared} or {t:mail.signature.own}.
4. Type the signature. You can format it like a message's text and place an image, such as a logo.
5. Press {t:tree.save}.

## How it works

A signature stands below a new message and above the quoted text in a reply. When you change the sender in the form, the signature changes too. The shared signature applies to accounts without one of their own.

The signature's images are sent in the message itself, so the recipient sees them without loading anything from outside.

The signature is kept in Ponistra, not at the provider. Ponistra does not use the provider's signature.

## Limits

A signature takes the same kinds of images as a message, and links must be valid. Changing a signature does not change messages already sent.
