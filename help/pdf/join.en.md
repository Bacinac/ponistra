# Joining files

Several PDFs from a folder are joined into one new file, in the order you set.

## How to use it

1. In a folder, select two or more PDFs.
2. On the selection bar, press {t:join.make} The same command is in the menu a right click on the selection opens.
3. In the {t:join.heading} dialog, type the {t:tree.name}. The suggested name begins with "Combined –" and the first file's name.
4. Under {t:join.order}, set the order of the files with the {t:join.earlier} and {t:join.later} buttons.
5. Press {t:join.submit}. The new file is saved beside the first file in the order and opens when it is ready.

## How it works

While the dialog checks whether each file can be joined, {t:join.checking} is shown beside it. The new file carries the notes and form values of the files joined, while comments stay with the files they were written on. The files joined do not change.

## Limits

- The command is offered only when nothing but PDFs is selected.
- A password-protected file, or a file that forbids taking its pages, cannot be joined: the dialog says so beside it, and {t:join.submit} stays disabled.
- When you may not add to the folder, the new file is saved among your own documents.
