# Files

A file that is not a Ponistra document, such as a PDF, an image, a text file, a video or a sound recording, opens on a page of its own and is shown in the browser.

## How to use it

1. In a folder, click the file, or go to it and press {k:Enter}.
2. The {t:file.download} button saves the file to your computer.
3. The page's menu offers {t:file.open}, which opens the file in a new browser tab.
4. The {t:access.share} button opens the file's sharing.

## How it works

What the page shows depends on the kind of file:

- A PDF is shown page by page, with notes, comments and forms.
- An image is shown whole, fitted to the window. PNG, JPEG, WebP and AVIF images can also be edited.
- A text file is shown read-only, with line numbers and search.
- Videos and sound recordings play in the browser. When the browser cannot play one, the page says so and advises downloading it.
- Other kinds Ponistra keeps but does not show: the page gives the file's name, kind and size and advises downloading it.

A downloaded PDF carries its notes, comments and the values entered in its form, and the text recognised on pages without text stays in it. When the file has any of these, the menu also offers {t:file.original}, which downloads the file as it was uploaded. The same holds for an edited image: the download is the image with its edits, while {t:file.original} gives it unedited.

## Limits

- In a {t:confined.label} folder a file can neither be downloaded nor opened separately.
- Notes and entered values cannot be written into a password-protected PDF. When such a file has notes, the download button reads {t:file.original} and downloads the file without them.
