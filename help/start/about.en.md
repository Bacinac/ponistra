# About

The {t:about.title} window says what Ponistra offers, which version the installation runs, under which licence it is used and whom to contact.

## How to use it

1. Open the account menu in the right corner of the header and choose {t:about.title}. Pressing the author's name at the foot of the left column opens the same window.
2. Below the description is the list of what it offers, then the {t:status.version} the installation runs.
3. Beside {t:about.contact} press the address to write to the author.
4. {t:about.licenceLink} and {t:about.source} open the licence's text and the source code in a new tab.

## How it works

The version is read from your installation's server, so it shows what is installed there, not what the browser remembers. The same version stands at the foot of the left column. Pressing the contact address opens the form of a new message with the recipient filled in.

## Limits

- If the version cannot be read, it says: {t:status.versionUnknown}
- The window states the licence's terms in one sentence; the licence's text is what counts.
