# Keyboard shortcuts

The list of the editor's commands that have a keyboard shortcut or start from what you type at the beginning of a paragraph.

## How to use it

1. In an open document press {k:Mod-/}. The {t:command.shortcuts} list opens.
2. The commands are arranged in groups: {t:commandGroup.history}, {t:commandGroup.clipboard}, {t:commandGroup.style}, {t:commandGroup.format}, {t:commandGroup.script}, {t:commandGroup.list}, {t:commandGroup.align}, {t:commandGroup.indent}, {t:commandGroup.insert}, {t:commandGroup.comment}, {t:commandGroup.table}, {t:commandGroup.tableData}, {t:commandGroup.note}, {t:commandGroup.part}, {t:commandGroup.find} and {t:commandGroup.help}.
3. {t:command.search} ({k:Alt-/}) takes you to the search box, which also offers the open document's commands.

## How it works

Each command stands beside its shortcut. On a Mac, iPhone and iPad the shortcuts are written with the signs ⌘, ⌥, ⇧ and ⌃, elsewhere with the words Ctrl, Alt and Shift.

Some commands start from what you type at the beginning of a paragraph, followed by {t:shortcuts.space}: `#` to `####` for headings, `-` for a bulleted list, `1.` for a numbered list and `[]` for a checklist.

## Limits

- The list holds only the groups in which at least one command has a shortcut or something to type. The other commands are on the toolbar and in the right-click menu.
